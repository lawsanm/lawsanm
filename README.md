### 💎 LauxUp — The Modern Moodle Experience
> *A Chrome extension that transforms the Moodle LMS into a premium, distraction-free workspace*

| Feature | Details |
|---------|---------|
| 🌙 Deep Dark Mode | Pre-injected at `document_start` for zero white flash |
| 📌 Notion-style Sidebar | Persistent, collapsible navigation with courses & assignments |
| 📊 Intelligent Dashboard | Redesigned greeting, progress rings, and beautiful course cards |
| ⌨️ Power Shortcuts | `D` Dashboard · `C` Courses · `A` Assignments · `[` Sidebar |
| 🏗️ Architecture | Manifest V3 · Modular CSS Design System · DOM-first approach |

**Tech:** `JavaScript` `CSS Design Tokens` `Chrome Extension API (MV3)` `DOM Manipulation`

---



### 🧘 LawZen — Focus & Anti-Procrastination
> *A personal Pomodoro timer and task manager built to fight procrastination*

| Feature | Details |
|---------|---------|
| ⏱️ Custom Pomodoro | Configurable focus intervals, short & long breaks |
| 🎨 Multiple Modes | Focus Mode · Ambient Mode · Home Mode |
| 📊 Daily Stats & Streaks | Track focus time, completed tasks, and consistency |
| 🎵 Ambient Themes | Curated visual + audio themes for deep focus |

**Tech:** `Next.js` `React` `TypeScript` `Tailwind CSS` `Zustand` `Framer Motion` `Recharts`

### 🧾 QSplit — Smart Bill Splitter

| Feature | Details |

| 🌗 Dark Mode | Persistent theme preference via localStorage |
| ✨ Premium UI | Micro-animations, input glows, and polished layouts |

**Tech:** `React` `Vite` `Tailwind CSS v4` `Lucide Icons`
